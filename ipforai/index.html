IP for AI：AI IP 检测、网络环境分与服务连通

IP for AI（ipforai.cc）帮你看清访问 AI 服务时的网络出口：当前 IPv4 / IPv6 画像、可解释的网络环境分（0–100），以及 ChatGPT、Claude、Gemini 等服务的连通性与分流出口。

检测什么

  1. 解析当前出口 IP（IPv4 与 IPv6 分别检测）；
  2. 查询地理位置；
  3. 匹配 ASN（出口属于哪家运营商或机房）；
  4. 检查代理 / VPN / Tor 信号；
  5. 检查风险名单；
  6. 汇总 AI 环境：给出可解释的网络环境分，检测公开资源连通性，并识别不同 AI 应用与厂商网络实际使用的公网出口（AI 分流出口）。

先看网络环境分，再核对 IPv4、IPv6 出口、ASN、地区与代理风险；单个标签或分数不足以判断原因。服务器上也可以用命令行做只读检测，见 CLI 说明 与 使用指南；英文页：/en。

几个常见概念

「IP 纯净度」是什么？

「IP 纯净度」是社区对出口类型、代理标记与风险记录的统称，没有统一标准。本站提供的是可解释的网络环境分（0–100）：结合可获取的出口与环境信号汇总；它不是各 AI 平台的官方评分，也不能预测封号。

机房 IP 与住宅 IP

住宅与机房描述网络用途和归属线索。本站结合 ASN、网络角色与多源证据进行推断，不能证明地址独享或实际使用者身份，也不能据此确定服务商如何处理请求。

原生 IP 与广播 IP

「原生 / 广播」是社区对注册信息与使用地区关系的称呼，并非统一标准。注册地与多源地理定位不同可作为核查线索，但不能确定服务商采用哪一份地区数据或是否允许账号使用。

为什么要分别看 IPv4 和 IPv6

双栈网络里，IPv4 和 IPv6 可能走不同出口、不同 ASN、不同地区或代理路径。只看一个，可能漏掉实际访问 AI 服务时用的另一条路径。

结果的边界

网络标签与环境分只描述当前网络的可观测属性，不等于账号状态；公开资源连通也不代表账号、订阅或完整功能可用。账号结果还可能受登录、行为、订阅、组织策略、地区资格和服务端规则影响，不能从单个网络标签推出封号或限制结论。

分流出口结果反映本次连接访问应用或厂商网络时使用的公网出口，不代表账号、订阅或产品功能状态。

English summary

ipforai.cc (IP for AI) is an AI network check: IPv4/IPv6 egress profile, an explainable 0–100 network environment score, connectivity to public endpoints of services such as ChatGPT, Claude and Gemini, and the public exits those apps or vendor networks actually use. “IP purity” is an informal community term, not a universal standard. The score is not an official platform rating and cannot predict bans; network labels do not determine account status. CLI: /cli · guides: /guides · English UI: /en.
