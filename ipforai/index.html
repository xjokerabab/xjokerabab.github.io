IP for AI：访问 AI 服务前，先看清自己的网络出口

IP for AI（ipforai.cc）是一个 AI 网络环境检测工具：打开页面即可看到当前出口 IP 的网络画像，以及 ChatGPT、Claude、Gemini 等服务的连通情况。

检测什么

  1. 解析当前出口 IP（IPv4 与 IPv6 分别检测）；
  2. 查询地理位置；
  3. 匹配 ASN（出口属于哪家运营商或机房）；
  4. 检查代理 / VPN / Tor 信号；
  5. 检查风险名单；
  6. 汇总 AI 环境：检测 AI 服务公开资源的连通性，并识别不同 AI 应用与厂商网络实际使用的公网出口（AI 分流出口）。

服务器上也可以用命令行做只读检测，用法见 ipforai.cc 的 CLI 说明。

几个常见概念

机房 IP 与住宅 IP

住宅 IP 由家庭宽带运营商分配给个人用户；机房 IP 属于数据中心，同一段地址可能被很多人共用，更容易被识别为代理或自动化流量。区别不在速度，而在风控系统怎么看这个出口。

原生 IP 与广播 IP

原生 IP 的注册地与实际使用地一致；广播 IP 是把其他地区的地址段广播到本地使用。AI 服务通常按注册地判断地区，所以广播 IP 容易出现「显示地区与实际所在地不符」。

为什么要分别看 IPv4 和 IPv6

双栈网络里，IPv4 和 IPv6 可能走不同出口、不同 ASN、不同地区。只看一个，可能漏掉实际访问 AI 服务时用的另一条路径。

结果的边界

IP for AI 不给单一「纯净度」分数，而是把各维度分别列出，因为不同 AI 服务对它们的权重不同。风险标签只描述网络的可观测属性，不等于账号会被限制；公开资源连通也不代表账号、订阅或完整功能可用。

English summary

ipforai.cc (IP for AI) is a network check for AI users. It shows your IPv4 and IPv6 egress IP, geolocation, ASN, proxy/VPN/Tor signals and blocklist status, tests connectivity to public endpoints of AI services such as ChatGPT, Claude and Gemini, and identifies which egress each AI provider actually sees. It reports each signal separately instead of a single "clean IP" score, and is explicit that network labels do not determine account status.
